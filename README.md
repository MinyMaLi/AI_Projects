# AI Projects — Tier 1 (Beginner)

A collection of small, self-contained Python agents built with the Claude API. Each project lives in its own folder with its own dependencies and setup.

---

## Projects

### 1. Email Triangle Assistant

> Watches your Gmail inbox and auto-drafts AI replies, threaded back into the original conversation.

**How it works:**
- Fetches the latest email from your Gmail inbox
- Sends it to Claude (Sonnet) to draft a context-aware reply that mirrors the sender's tone
- Skips newsletters, automated notifications, and no-reply senders (`[SKIP: reason]`)
- Saves a Gmail draft threaded to the original email
- Always writes a local `.md` audit copy to `outputs/`

A `watcher.py` script polls for new emails continuously so drafts appear automatically.

**Stack:** `anthropic`, `google-api-python-client`, `python-dotenv`

**Setup:**
```bash
cd "Email Triagle assistant"
pip install -r requirements.txt
# Add credentials.json (Google Cloud Console → OAuth 2.0 Desktop app)
# Create .env with ANTHROPIC_API_KEY and optionally LASHA_PROFILE
python pipeline.py        # run once
python watcher.py         # run continuously
```

`.env` variables:
```
ANTHROPIC_API_KEY=sk-ant-...
LASHA_PROFILE=Optional one-paragraph description injected into the AI system prompt
```

### 2. Daily Brief

> Sends you a styled HTML morning briefing — weather, news, unread email, and calendar — generated by Claude.

**How it works:**
1. Fetches weather from Open-Meteo (free, no key required)
2. Searches for top news via Tavily (Prague, global, AI, stocks, crypto)
3. Pulls unread Gmail and today's Google Calendar events
4. Passes everything to Claude to write a styled HTML email
5. Sends the brief to your email and saves it locally under `outputs/YYYY-MM-DD.html`

Designed to run automatically each morning via Windows Task Scheduler (`setup_task.bat`).

**Stack:** `anthropic`, `google-api-python-client`, `tavily-python`, `requests`, `python-dotenv`

**Setup:**
```bash
cd "Daily brief"
pip install -r requirements.txt
# Add credentials.json (Google Cloud Console → OAuth 2.0 Desktop app)
python setup_auth.py      # first-time Google OAuth
python brief.py           # run the brief
```

`.env` variables:
```
ANTHROPIC_API_KEY=sk-ant-...
TAVILY_API_KEY=tvly-...
LOCATION=Prague
USER_EMAIL=you@example.com
```

### 3. Document QA

> CLI agent that answers questions strictly grounded in your local PDF, DOCX, MD, or TXT files — with verbatim citations, no hallucination.

**How it works:**
- Drop documents into `docs/`
- Ask questions in a terminal chat loop
- Claude must cite verbatim supporting quotes before answering; returns a `not_found` flag for out-of-scope questions
- If the corpus exceeds ~150k tokens, BM25 retrieval selects the top-8 relevant chunks per question
- Prompt caching keeps repeated-session costs low (~90% cheaper for corpus tokens after the first question)

**Stack:** `anthropic`, `pymupdf`, `python-docx`, `rank-bm25`, `python-dotenv`

**Setup:**
```bash
cd "Document QA"
pip install -r requirements.txt
# Create .env with ANTHROPIC_API_KEY
# Drop .pdf / .docx / .md / .txt files into docs/
python main.py
```

`.env` variables:
```
ANTHROPIC_API_KEY=sk-ant-...
```

## Common requirements

All projects require:
- Python 3.10+
- An [Anthropic API key](https://console.anthropic.com/)
- Projects that use Gmail or Google Calendar also need a `credentials.json` OAuth 2.0 client file from [Google Cloud Console](https://console.cloud.google.com/)

**Files never committed to the repo:**
- `.env` — API keys
- `credentials.json` — Google OAuth client secrets
- `token.json` — auto-generated OAuth token (created on first run)
- `outputs/` — generated drafts and briefs
